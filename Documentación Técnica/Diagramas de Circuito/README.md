Diagramas de circuito — CAMI

Evolución del prototipo

El archivo Diagrama.jpeg representa una versión anterior del prototipo CAMI, que utilizaba un sensor MQ-135, un LED rojo y un buzzer.

Este diagrama se conserva como evidencia del desarrollo del proyecto.

Versión actual

El firmware CAMI-SB2 contempla:

* Sensor MQ-7 conectado a GPIO34 mediante divisor de tensión.
* Luz verde conectada a GPIO25.
* Luz amarilla conectada a GPIO26.
* Luz roja conectada a GPIO27.
* Buzzer controlado desde GPIO23 mediante transistor BC547.

Verificación del montaje

Las conexiones definitivas deben comprobarse físicamente y documentarse en un nuevo diagrama.

El circuito antiguo no representa el montaje final.

CAMI es un prototipo académico y no un detector de gases certificado.
